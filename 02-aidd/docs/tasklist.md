## Итерация 1. Ответ модели

- [x] Бот запускается локально и на текст отвечает в том же чате
- [x] Смена модели меняет ответ после перезапуска
- [x] Если настройки не хватает, бот не стартует и сообщает, чего нет
- [x] Проверка: написать текст и получить ответ в том же чате; убрать одну настройку и убедиться, что бот не запустился

## Итерация 2. Память диалога

- [x] Уточняющий вопрос учитывает предыдущие реплики
- [x] У каждого чата своя переписка
- [x] В памяти остаются последние 20 реплик
- [x] После перезапуска память пустая
- [x] Проверка: диалог из нескольких реплик, последние 20 реплик, перезапуск

## Итерация 3. Границы диалога

- [x] Стикер, фото, голос и другие вложения — одна фраза, что принимается только текст; в память не пишется
- [x] Пустой ответ или ошибка модели — короткая фраза об ошибке; фраза в память не пишется, вопрос пользователя остаётся
- [x] Проверка: отправить стикер; нарушить доступ к модели, отправить текст и продолжить диалог

## Итерация 4. Логи

- [x] На старте видно, что бот запущен, и имя модели
- [x] На текст пишется чат, без текста реплики и ответа
- [x] На вложение пишется чат и то, что сообщение пропущено
- [x] На сбой пишется чат и текст ошибки
- [x] Если при старте не хватает настройки, её имя пишется в лог и процесс завершается
- [x] Проверка: пройти прежние сценарии и сверить вывод

## Итерация 5. Контейнер

- [ ] Образ собирается, контейнер запускается с теми же настройками
- [ ] Короткий диалог в контейнере ведёт себя так же, как локальный запуск
- [ ] Проверка: собрать, запустить, написать боту, остановить контейнер
