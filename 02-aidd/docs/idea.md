# Идея: LLM-ассистент

LLM-ассистент выполняется в виде Telegram-бота.

Бот ведёт диалог в роли нутрициолога и фитнес-тренера. Он составляет рацион, оценивает калории, советует по питанию и даёт практические лайфхаки, помогает с программой тренировок и техникой упражнений. Цель, запросы и ограничения пользователя берутся из переписки.

Роль задаётся системным промптом LLM.
