# ai-agents

Репозиторий домашних заданий по курсу [«AI-driven разработка ИИ-агентов»](https://github.com/llmstart-ru/llmstart-agents).

Здесь собраны решения практических заданий: от работы с LLM API до RAG, агентов на LangChain и LangGraph, MCP и мультиагентных систем.

Папки модулей добавляются по мере выполнения заданий. У каждого модуля — своя директория с кодом, зависимостями и кратким описанием решения.

```text
ai-agents/
```

## Как запускать

Инструкции по запуску появятся здесь вместе с решениями заданий. Для каждого модуля будут указаны окружение, зависимости и команда запуска.

Секреты (API-ключи и токены) хранятся в локальном `.env` и не попадают в репозиторий.
